A compact handheld device made using:
- Arduino nano
- 0.96" OLD display I2C
- 3.7v lipo battery
- Analog joystick
- charging module.

Features:
- Calculator [not fully functional] :(
- snake game
- menu system
- stop watch
- notes.

Made this project while I was learning things, so the repo isn't organized.
